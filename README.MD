# GitHub User API

A simple project for using the GitHub API.

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/luizlost01/GithubUserAPI.git
   cd Github_UserAPI
   ```

3. Run the application:
   ```bash
   node index.js <"Username">
   ```
